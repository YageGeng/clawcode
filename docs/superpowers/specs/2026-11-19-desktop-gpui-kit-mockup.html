三层表面 ① chrome 底面（标题栏 / 侧栏）：title_bar / sidebar，不画分隔线，靠和卡片的色差分区。
② 内容卡片（轨道 / 会话 / inspector）：background + 1px border + radius_lg，浅色主题带极淡阴影，深色只靠描边。卡片之间、卡片到窗口边都是 8px。
③ 弹出层（菜单 / Select / 命令面板 / Dialog）：popover，阴影最强。
Icon button 只有两档 轨道：34px 框 / 18px 图标 / radius 8；工具栏与行内：26px 框 / 16px 图标 / radius 6（等同 gpui-kit Button::ghost().small()）。
全部用 Lucide（gpui-kit 的 IconName），同一描边粗细。状态：静止 muted → hover accent 底 → 选中 sidebar_accent 底 + foreground → 禁用降不透明度；纯图标按钮都有 tooltip，有快捷键的显示出来。
内容区节奏 正文列最大宽约 680px，居中；用户消息是右对齐的 muted 气泡；助手正文直接排版，不加气泡。
连续的工具调用合成一个分组框，行之间用 hairline 分隔：图标 · 动词 · 等宽路径 · 右侧状态（✓ / 转圈 / +86 −41）。thinking 是一行可折叠的 muted 文字。
Composer 是浮起的大圆角卡片，左边是附件和计划模式，右边是上下文环、模型、发送/停止。
