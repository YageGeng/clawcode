# Desktop 外壳重构（M3b）设计

本文替换 [Desktop 客户端设计](./2026-11-19-desktop-gpui-kit-design.md) 中关于外壳布局、侧栏、Tab、inspector、工作区工具展示和设置页的部分（见第 12 节）。没有被替换的章节仍然有效。

## 1. 背景与目标

M3 把文件树和变更放在左侧栏的轨道模式里，把文件预览、diff 和设置做成主卡片的 Tab。用户在使用中指出了这些问题：

- 文件树和变更属于工作区，也就是属于当前会话所在的那个工作区，不该和会话列表共用左侧栏。
- 左边的图标轨道不该是一张内嵌卡片；会话列表才应该是。
- 设置做成 Tab，交互不好。
- 「最近」分组里的会话行显示工作区名，信息太多。

M3b 参照 T3 Code（`~/Documents/WorkSpace/t3code`，`apps/web` 的 `ThreadDetailsPanel`、`rightPanelStore`、`GitActionsControl`、`ThreadRelationshipsControl`）重新组织外壳：

- 左侧只有会话卡片。
- 会话相关的工作区信息放在浮在对话区右上角的**会话详情卡**里。
- 变更、文件、文件预览和子智能体会话放在每个会话独立的**右侧标签面板**里。
- 设置改为模态对话框，并新增字体设置。

成功标准：第 13 节的测试全部通过；在真实后端上，第 13 节的验收清单逐项截图确认。

## 2. 已确认的决策

| # | 决策 |
| --- | --- |
| 1 | 去掉轨道。左侧只有会话卡片，它是内嵌卡片（6.1 第 2 层）。 |
| 2 | 文件树、变更、文件预览、子智能体会话都放进右侧标签面板，每个会话一套，照 T3。 |
| 3 | 变更是一个标签：文件列表加连续的 diff，可以切换范围，照 T3。不再一个文件一个 diff Tab。 |
| 4 | 会话详情卡照 T3：浮在对话区右上角，空间不够时收进顶栏按钮，以弹出层显示；高度不够时按档降级；每一项可以通过右键菜单开关。 |
| 5 | 子智能体永远不出现在左侧列表里，照 T3；从详情卡的「会话关系」进入。 |
| 6 | 不做 Git 写操作：提交、推送、切换或新建分支、PR。分支只显示。 |
| 7 | 不做 T3 中 clawcode 后端没有对应能力的项：环境和 worktree、项目脚本、开发服务器、自动化、侧聊。 |
| 8 | 设置是窗口内的模态对话框，不再是 Tab。 |
| 9 | 字体设置分界面和代码两组，每组都有字体、字号、字重；字重是数字输入框，没有预设档位。 |
| 10 | 「最近」分组的会话行不显示工作区名。 |
| 11 | M3 和 M3b 合成一个提交，M3 不单独提交。 |

## 3. 布局与表面

```
┌ 标题栏：[◧] 文件 视图                Clawcode                      – ▢ ✕ ┐
│┌ 会话卡片 ──┐ ┌ 主卡片 ──────────────────────────────┐ ┌ 右侧面板 ────────┐│
││ 会话  ☰ ⌕  │ │ [会话 A][会话 B]  运行中 │⋯│⑂ ▤ ⓘ ◨ │ │ [变更][文件][a.rs]││
││ ✎ 新会话   │ ├──────────────────────────────────────┤ ├──────────────────┤│
││ 工作区   + │ │                        ┌ 详情卡 ────┐│ │ 对比 origin/main ││
││  clawcode ⌄│ │      transcript        │ clawcode   ││ │ M Cargo.toml  +3 ││
││   会话 A   │ │                        │ ⑂ main     ││ │ ───────────────  ││
││ 最近       │ │                        │ 改动 +3 −1 ││ │ diff …           ││
││  会话 B    │ │  ┌ composer ────────┐  └────────────┘│ │                  ││
││ ⚙          │ │  └──────────────────┘                │ │                  ││
│└────────────┘ └──────────────────────────────────────┘ └──────────────────┘│
└────────────────────────────────────────────────────────────────────────────┘
```

**表面**
- 会话卡片、主卡片、右侧面板都是内容卡片：主题 `background`、1px `border`、`radius_lg`，浅色主题加极淡的阴影。卡片之间、卡片到窗口边缘都留 8px（spacing `sm`）。
- chrome 底面只剩标题栏和卡片之间的缝隙。
- 会话详情卡是主卡片里的嵌套表面，圆角按 `inner radius ≈ outer radius − gap` 取档。它以弹出层出现时，用弹出层表面（6.1 第 3 层）。

**尺寸**

| 区域 | 最小 | 默认 | 最大 | 开关 |
| --- | --- | --- | --- | --- |
| 会话卡片 | 200px | 248px | 400px | 标题栏 [◧]，Ctrl+B |
| 主卡片 | 480px | 剩余宽度 | — | — |
| 右侧面板 | 320px | 480px | 窗口宽度 − 会话卡片 − 480px − 间距 | 主卡片顶栏 [◨]，Ctrl+J |
| 会话详情卡 | 固定 280px | | | 主卡片顶栏 [ⓘ] |

- 两张卡片的宽度都以 px 持久化，恢复时按当前窗口 clamp。所有 px 都是默认字号（rem = 16px）下的值，实现时换算成 rem。
- 右侧面板并排放不下（主卡片会小于 480px）时，变成从右边滑出、盖在主卡片上的抽屉，背后加遮罩；Esc 或点遮罩关闭。窗口再窄、主卡片仍小于 480px 时，收起会话卡片。
- 右侧面板可以最大化：占满主卡片的位置，主卡片隐藏。再点一次恢复。

**主卡片顶栏右侧**，从左到右：
- 运行状态；
- 竖分隔线；
- `⋯` 会话菜单；
- [⑂ 变更]（`git-compare`）：打开右侧面板，切到「变更」；不是 Git 仓库时禁用，提示「不是 Git 仓库」；
- [▤ 文件]（`folder-tree`）：打开右侧面板，切到「文件」；
- [ⓘ 详情]：开关会话详情卡；
- [◨]：开关右侧面板。

按钮都是 `Button::ghost().small()`，带 tooltip 和快捷键。没有活动 Tab 时（空状态），只显示 [◨]。

**主卡片的 Tab 条**只放会话 Tab 和新会话草稿 Tab。文件、diff、设置三种 Tab 都去掉。

## 4. 左侧会话卡片

- **顶部不变：** 标题「会话」，加筛选和搜索（Ctrl+K）两个按钮，下面是「新会话」（Ctrl+N）。搜索和筛选的行为同原设计 5.4。
- **工作区行：**
  - 一行依次是文件夹图标、名称、`⑂ 分支`、展开箭头。分支名过长时由布局截断，显示省略号（最大宽度约 6rem）。
  - 展开状态的唯一来源仍然是 `desktop.json` 里工作区的 `expanded`。
  - 右键菜单：新会话、在文件管理器中显示、上移、下移、从列表移除。目录已不存在的工作区禁用「新会话」。
  - 点一个工作区，它就成为没有活动 Tab 时新会话默认使用的工作区。
- **最近：** 跨工作区的最近 10 个会话。行尾只显示状态图标或相对时间，**不显示工作区名**。
- **子智能体：** 带 `parentSessionId` 的会话不出现在任何分组里，没有开关。当前活动 Tab 是子智能体时，高亮它最近的、在列表中有行的那个祖先会话。
- **底部：** 左下角固定设置按钮（`settings-2`，`Button::ghost()`，tooltip「设置 Ctrl+,」），点了打开设置对话框（第 7 节）。
- **拖放：** 文件夹拖到整张卡片上任意位置，都加成工作区，拖动时卡片显示 `accent` 高亮；拖入的普通文件忽略。

## 5. 会话详情卡

### 5.1 位置与开关

- **内嵌显示：** 主卡片正文宽度 ≥ transcript 列宽（约 680px）+ 280px + 2 × 8px 时，详情卡内嵌显示：固定在主卡片正文区的右上角，距顶栏和右边各 8px，不遮挡居中的 transcript 列。
- **弹出层显示：** 宽度不够时，点 [ⓘ] 后以 Popover 显示，挂在按钮下方；点外面或按 Esc 关闭。
- **开关状态：** 内嵌显示时，[ⓘ] 开关它是否显示，状态全局持久化，默认打开。弹出层不持久化。
- **跟随：** 详情卡跟随主卡片的活动 Tab。会话 Tab 和新会话草稿 Tab 都有详情卡；草稿没有「会话关系」组。

### 5.2 内容

| 组 | 行 | 行为 |
| --- | --- | --- |
| 工作区 | 工作区名 · 在…中打开 ⌄ | 主按钮用上次选择的方式打开工作区目录；下拉列出「文件管理器」和检测到的外部编辑器（见 5.4） |
| 版本控制 | ⑂ 分支 | 只显示，分离 HEAD 时显示短提交号。不是 Git 仓库时整组隐藏 |
| | 改动 对比 {基准} +x −y | 基准规则见第 8 节。悬停 Tooltip 显示每个文件的增删明细。点击打开右侧面板的「变更」标签，范围为「对比基准」 |
| 会话关系 | 父会话 | 当前会话是子智能体时显示（`corner-left-up` 图标），点击在主卡片打开父会话 |
| | 运行中的子智能体 | `bot` 图标、名称、状态图标或耗时 |
| | 之前的智能体 · N | 已结束的子智能体，默认折叠 |
| 其他 | 上下文 | 上下文用量（复用 composer 上下文环的数据），默认隐藏 |
| | 用量 | 最近一次 Run 的输入、输出和缓存命中，默认隐藏 |

- **点击子智能体行：** 按「子智能体默认打开位置」（第 7 节，默认是右侧面板）打开；Ctrl+点击打开到另一处。打开到主卡片时是普通会话 Tab，标题前加 `bot` 图标。
- **刷新：** 会话关系组的数据来自会话目录的 `parentSessionId`，随会话目录刷新。版本控制组的刷新时机同 M3 的变更：右侧面板「变更」标签被打开时、该工作区任一会话的 Run 结束时、点「变更」标签里的刷新按钮时。

### 5.3 显示项与降级

- **选择显示的内容：** 在卡片上右键（或卡片为空时显示的「选择显示的内容」按钮）打开菜单，逐项勾选：在…中打开、分支、改动、会话关系、上下文、用量。只保存和默认值不同的选择，保存在 `desktop.json` 的 `details_items`。
- **降级：** 卡片最大高度 = 主卡片正文高度 − 16px。三档从上往下试，取第一个放得下的：
  - **完整：** 所有开启的项；
  - **紧凑：** 去掉「在…中打开」「之前的智能体」「上下文」「用量」；
  - **精简：** 只剩分支和改动。

  精简也放不下时，卡片内部滚动。
- **空卡片：** 一组里没有可显示的行时，这一组连同它的分隔线一起不画。全部为空时，只显示「选择显示的内容」按钮。

### 5.4 外部编辑器

- 只检测本机：在 PATH 里查找 `zed`、`code`、`cursor`、`codium`、`subl`，结果在应用启动时缓存。
- 「文件管理器」用现有的「在文件管理器中显示」实现。
- 选择保存在 `desktop.json` 的 `open_in`。保存的编辑器不再存在时，回退到文件管理器。
- 启动编辑器失败时，弹通知，说明命令和错误。
- 远程工作区（原设计 4.6）以后由后端提供，这一版不做。

## 6. 右侧标签面板

### 6.1 归属与持久化

- 每个**面板归属者**一套面板状态：会话 Tab 用会话 id；新会话草稿用草稿选中的工作区路径。
- 新的归属者面板默认关闭、没有标签，照 T3。
- 草稿发出第一条消息、变成会话时，面板状态转到新会话名下。
- 状态包括：是否打开、标签列表（类型和标识）、活动标签、是否最大化。保存在 `desktop.json` 的 `panels`，以归属者为键。
- 会话被删除或不在会话目录里时，在会话目录刷新时清理它的面板状态。总数超过 50 个时，按最近使用时间淘汰。
- 面板宽度全局保存，不按会话。
- 恢复时只重建标签，内容在标签第一次被激活时才加载。

### 6.2 标签类型

| 标签 | 数量 | 内容 | 打开方式 |
| --- | --- | --- | --- |
| **变更** | 每个归属者至多一个 | 顶部是范围分段「对比 {基准} · 未暂存」、合计 +x −y、刷新按钮；左栏是文件列表（状态字母、文件名、灰色目录、+x −y，按可视范围渲染）；右栏是整个工作区的 patch，用 gpui-kit `Diff` 多文件显示。点列表项时调用 `DiffState::scroll_to_file` 滚到该文件 | 顶栏 [⑂]、Ctrl+Shift+G、详情卡的「改动」行 |
| **文件** | 每个归属者至多一个 | 搬用 M3 的懒加载文件树；标签下方的小工具条有「显示隐藏文件」开关和刷新按钮 | 顶栏 [▤]、Ctrl+Shift+E |
| **文件预览** | 每个文件一个 | 搬用 M3 的只读预览（语法高亮、行号、过大或二进制时显示说明）；文件没变时，重新激活不重置光标和滚动位置 | 文件树里点文件 |
| **子智能体** | 每个子智能体一个 | 子智能体会话的 transcript 和 composer，复用 `SessionView` | 详情卡里的子智能体行 |

- **标签条：** 每个标签有图标和标题，有关闭按钮，鼠标中键也能关闭；条的右侧是最大化按钮和关闭面板按钮。
- **自动打开面板：** 面板关着时，从上表任何入口打开标签，面板会一起打开。
- **范围切换：** 两个范围下的 patch 和列表分别缓存。切换时先显示已缓存的内容，再在后台刷新。
- **大小限制：** patch 被截断（超过 2 MiB）时，标签顶部显示「差异过大，只显示前 2 MiB」，并允许解析被截断的 hunk。

## 7. 设置对话框与字体

### 7.1 对话框

- **入口：** 会话卡片左下角的齿轮、Ctrl+,、标题栏菜单「文件 → 设置…」打开同一个对话框（gpui-kit `Dialog`）。已经打开时，只把焦点移回对话框。
- **尺寸：** 约 880×640；窗口较小时缩小，四周至少留 40px。
- **关闭：** Esc 或 ✕ 关闭，焦点回到打开它的那个控件。
- **生效：** 每项改动都立即生效并写入 `desktop.json`，没有「确定 / 取消」。
- **布局：** 左边是搜索框和分页列表，右边是当前分页，复用 gpui-kit `Settings` 组件。

| 分页 | 设置项 |
| --- | --- |
| 通用 | 语言；子智能体默认打开位置（右侧面板 / 主区域，默认右侧面板） |
| 外观 | 模式；浅色主题；深色主题；浅色文件图标；深色文件图标 |
| 字体 | 界面字体、界面字号、界面字重；代码字体、代码字号、代码字重 |

### 7.2 字体

| 设置 | 控件 | 取值 | 默认 | 作用于 |
| --- | --- | --- | --- | --- |
| 界面字体 | 可筛选的下拉框 | 「默认」加系统所有字体（`text_system().all_font_names()`） | 默认（主题的 `font_family`） | 主题 `font_family` |
| 界面字号 | 数字输入 | 12–20，步长 1 | 16 | 主题 `font_size`，rem 跟着变 |
| 界面字重 | 数字输入 | 100–900 的整数，−/+ 步长 50 | 400 | 窗口根元素的文字样式，往下传 |
| 代码字体 | 可筛选的下拉框 | 「默认」加系统所有字体 | 默认（主题的 `mono_font_family`） | 主题 `mono_font_family` |
| 代码字号 | 数字输入 | 10–24，步长 1 | 14 | 主题 `mono_font_size` |
| 代码字重 | 数字输入 | 100–900 的整数，−/+ 步长 50 | 400 | 等宽文字所在容器的文字样式 |

- **作用范围：** 代码字体那一组作用在代码块、diff、文件预览、工具输出、路径和快捷键文字上。gpui-kit 的编辑器和 `Diff` 本来就读主题的等宽字体和字号。
- **非法值：** 输入超出范围的字号或字重时，夹到边界值。
- **字体失效：** 保存的字体不在系统里时，按「默认」显示；设置值保留，下次字体回来时继续生效。
- **重新测量：** 界面字号或代码字号变化后，transcript 整体 `remeasure`，同原设计第 10 节。
- **主题切换：** 切换主题会重建主题对象。字体设置在每次应用主题之后重新套用，所以不会被主题文件里的字体覆盖。

## 8. 后端扩展

新增字段和参数，不改变 M3 已有方法在旧参数下的语义。

1. **`_clawcode/workspace/git_status`** 在 `Repository` 结果中加上：
   - `base`：对比基准的显示名，例如 `origin/main`；没有上游时是 `HEAD`。
   - 每个 `WorkspaceChange` 加 `insertions` 和 `deletions`，二进制文件为 `null`。
   - 合计 `insertions` / `deletions`。

   **基准规则：**
   - 当前分支有上游时，基准是 `git merge-base HEAD @{upstream}`，显示名是上游名；
   - 没有上游、或分离 HEAD 时，基准是 `HEAD`；
   - 还没有提交的仓库，所有文件都算新增。

   **行数来源：** 「对比基准」的增删行数来自 `git diff --numstat -z <base>`，未跟踪文件按文件行数计为新增。
2. **`_clawcode/workspace/git_diff`** 新增两个可选参数：
   - `scope`：`base`（默认）或 `unstaged`。`unstaged` 用 `git diff`，对比工作区和暂存区；`base` 用 `git diff <base>`，未跟踪文件仍用 `--no-index`。
   - `path` 可以不填。不填时返回整个工作区在该范围下的 patch（含未跟踪文件），总大小仍受 2 MiB 限制。
3. **约束：** 路径校验（`GIT_LITERAL_PATHSPECS`、越界拒绝）、`GIT_OPTIONAL_LOCKS=0`、10 秒超时，全部沿用 M3。

## 9. 状态与持久化（`desktop.json`）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `layout.sidebar_open` / `sidebar_width` | 保留 | 会话卡片 |
| `layout.panel_width` | px | 右侧面板宽度 |
| `layout.details_open` | bool | 详情卡内嵌显示时是否打开，默认 `true` |
| `panels` | 归属者 → 面板状态 | 第 6.1 节 |
| `details_items` | 项 → bool | 只存和默认值不同的项 |
| `open_in` | `file_manager` 或编辑器命令名 | 第 5.4 节 |
| `subagent_open_target` | `panel` / `main` | 默认 `panel` |
| `appearance.ui_font` / `ui_font_weight` / `font_size` | 字符串或空 / 整数 / 数字 | 字号沿用现有的 `font_size` |
| `appearance.code_font` / `code_font_size` / `code_font_weight` | 字符串或空 / 数字 / 整数 | |

- **字段的取舍：**
  - 删除 `layout.sidebar_mode`；
  - 设置 Tab、文件 Tab、diff Tab 不再写入 `tabs.open`。
- **兼容旧文件：** 读到旧字段和旧 Tab 时忽略。所有枚举值不认识时回退到默认值（`#[serde(other)]`），不会让整个文件读取失败。

## 11. 空状态与错误

- **没有任何工作区：** 详情卡只显示「添加一个工作区后可查看」和「添加工作区…」按钮；右侧面板的「变更」「文件」显示同样的说明。
- **当前工作区的目录已不存在：** 详情卡显示「找不到文件夹」；「变更」「文件」标签显示错误和重试按钮。
- **不是 Git 仓库或没装 git：** 版本控制组隐藏，[⑂] 禁用，「变更」标签显示对应的说明（沿用 M3 的文案）。
- **右侧面板标签加载失败：** 在标签里显示错误和重试按钮，不弹全局通知。
- **当前会话没有子智能体，也不是子智能体：** 会话关系组隐藏。

## 13. 测试与验收

**后端（acp、protocol）**
- `git_status` 的增删行数和基准：
  - 有上游时用 merge-base，显示名是上游名；
  - 没有上游或分离 HEAD 时回退到 HEAD；
  - 还没有提交的仓库；
  - 二进制文件的行数为 `null`；
  - 未跟踪文件计为新增。
- `git_diff`：
  - `scope = unstaged` 只包含未暂存的改动；
  - 不填 `path` 时返回整个工作区的 patch，包含未跟踪文件，并受 2 MiB 限制；
  - 字面路径和越界拒绝的回归测试。

**桌面端（`crates/desktop/tests`）**
- 外壳：没有轨道；会话卡片、主卡片、右侧面板都是卡片；Ctrl+B / Ctrl+J / Ctrl+Shift+G / Ctrl+Shift+E 的行为。
- 会话卡片：
  - 「最近」分组的行没有工作区名；
  - 子智能体不在任何分组里；
  - 打开子智能体时高亮父会话；
  - 拖入文件夹。
- 详情卡：
  - 内嵌和弹出层两种显示的切换条件；
  - 每一项的显示开关和只存非默认值；
  - 三档降级；
  - 「改动」行打开「变更」标签；
  - 子智能体行按偏好打开到面板或主卡片，Ctrl+点击打开到另一处；
  - 父会话行。
- 右侧面板：
  - 面板状态按会话分别保存，重启后恢复；
  - 草稿发送后，面板状态转到新会话名下；
  - 删除会话时清理面板状态；
  - 窗口窄时变成抽屉；
  - 最大化；
  - 「变更」的范围切换和定位到文件；
  - 文件预览重新激活时不重置位置。
- 设置对话框：
  - 三个入口打开同一个对话框；
  - Esc 关闭并归还焦点；
  - 改动立即写入。
- 字体：
  - 六项设置写入主题，或作用在对应的文字上；
  - 超出范围的值被夹住；
  - 失效字体回退到默认；
  - 切换主题后字体设置仍在。
- `desktop.json`：旧文件（含 `sidebar_mode`、设置 Tab、文件 Tab、diff Tab）能读取，并忽略这些旧内容。

**真实界面验收**
- 环境：production backend 和真实 provider，在隔离的 KWin 加软件渲染环境里截图逐项确认。
- 浅色和深色主题、中文和英文、960×640 和 1280×820 两种窗口尺寸都要覆盖。
- 内容覆盖：详情卡三档降级、右侧面板抽屉形态、变更标签的整个工作区 diff、字体设置的视觉效果。
